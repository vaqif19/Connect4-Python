# Connect4-Python
Connect 4 OnlinePygame kitabxanasından istifadə edilərək Vaqif İsmayılov tərəfindən hazırlanmış, həm onlayn, həm də eyni kompüterdə (lokal) oynana bilən klassik Connect 4 (Dördünü Birləşdir) oyunudur.   
Xüsusiyyətlər
Onlayn Çoxoyunçulu Rejim (Play Online): TCP soketləri və JSON mesajlaşma infrastrukturu sayəsində lokal şəbəkədə (LAN) və ya internet üzərindən dostlarınızla qarşılıqlı oynaya bilərsiniz. Otaq yaratmaq (Host) və port nömrəsi (standart: 5555) ilə otağa qoşulmaq (Join) mümkündür.   Süni İntellektə Qarşı (Vs Computer): İrəliyə doğru gedişləri hesablayan inteqrasiya olunmuş süni intellekt rəqibinə qarşı təkbaşına oynaya bilərsiniz.   Lokal 2 Oyunçu (Local 2 Players): Eyni kompüter ekranında iki nəfərin oynamasına imkan yaradır.   Fərdiləşdirilə bilən Ayarlar: Ekran ölçüsü, FPS limitləri (30, 60, 120, 144), tam ekran (fullscreen) rejimi, hissəcik effektləri (sparkles) və animasiya sürəti menyudan tənzimlənə bilər.   Prosedural Səs Sistemi: Heç bir xarici səs faylına (MP3/WAV) ehtiyac duymadan, riyazi dalğalarla anlıq yaradılan arxa plan musiqisi və səs effektləri mövcuddur. Ümumi, Musiqi və Effekt səsləri ayrı-ayrılıqda idarə edilə bilər.   Vizuallıq və Dizayn: Açıq pastel rəng palitrası, alternativ "sticker" dizaynı (lavanda/şaftalı arxa plan) və əsas menyuda süni intellektin öz-özü ilə oynadığı demo taxtası yer alır.   
Oynanış
Oyunçular (1. Oyunçu Coral və 2. Oyunçu Mint) növbə ilə 7 sütun və 6 sətirdən ibarət taxtaya öz disklərini atırlar.   Üfüqi, şaquli və ya diaqonal olaraq 4 diskini yan-yana gətirən ilk oyunçu qalib gəlir.   Sütunu siçan (mouse) ilə seçə, klaviaturadakı 1-7 rəqəmlərindən istifadə edə və ya yön düymələri ilə hərəkət edib Enter/Space düyməsi ilə diski ata bilərsiniz. Esc düyməsi oyunu fasiləyə (pause) verir.   
Tələblər və Quraşdırılma
Oyunu işə salmaq üçün sisteminizdə Python və Pygame quraşdırılmış olmalıdır.
